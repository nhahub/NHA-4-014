\# 🚗 Object Detection for Autonomous Vehicles

\## Data Collection, Exploration \& Preprocessing



\### Project Overview

This repository contains the data pipeline for an autonomous vehicle 

object detection system. My role covers data collection, exploratory 

data analysis (EDA), cleaning, preprocessing, and augmentation.



\### Dataset

\- \*\*Source:\*\* Roboflow Universe

\- \*\*Classes:\*\* Cars, Pedestrians, Cyclists, Trucks

\- \*\*Format:\*\* YOLO
